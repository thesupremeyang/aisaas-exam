### 前端构建注意（本次踩到）

`pnpm build:main` 在 pnpm 11 下会先跑 `pnpm install` 校验，因 `ERR_PNPM_IGNORED_BUILDS`
（@parcel/watcher / esbuild 等被忽略的构建脚本）直接失败。绕过方式：

```bash
cd ui && ./node_modules/.bin/vite build --mode main
```

产物仍是 `ui/dist-main`，与 `pnpm build:main` 一致（本次构建已验证：
`MAX_RECONNECT_ATTEMPTS:40`、0 处 1440、`giveUp`/`重新连接`/`AI 调用失败` 均在）。
若要长期用 pnpm 脚本，需先 `pnpm approve-builds` 或把 `verify-deps-before-run` 关掉。
